# 教训门禁系统

创建日期: 2026-08-08
来源: 全历史复盘_终极总结.md + v3迁移计划

---

# GATE-1: 写完代码不等于功能完成
- 强制等级: BLOCKER
- 门禁: 每个Vue组件开发完成后必须运行CDP行为验证(Input.dispatchMouseEvent), 截图+JSON日志+时间戳三者缺一禁止进入下一波
- 检查方法: scripts/gate_cdp_verify.js

# GATE-2: CDP假阳性
- 强制等级: BLOCKER
- 门禁: CDP验证脚本中禁止Runtime.evaluate调用, 必须用Input.dispatchMouseEvent模拟真实鼠标坐标
- 检查方法: 扫描测试脚本中是否有Runtime.evaluate

# GATE-3: CSS只加不删
- 强制等级: BLOCKER
- 门禁: Vue组件用scoped CSS隔离, 全局样式修改前必须全文搜索选择器。封装前重复选择器检测=0
- 检查方法: scripts/gate_css_conflicts.js

# GATE-4: 封装版与源文件不一致
- 强制等级: BLOCKER
- 门禁: 每波完成后必须封装一次, 安装新版本实测。封装后安装版验证清单全部PASS才算完成
- 检查方法: scripts/gate_install_verify.js

# GATE-5: PowerShell写中文文件
- 强制等级: BLOCKER
- 门禁: 所有中文文件写入必须用Node.js fs, 禁止PowerShell cmdlet(Set-Content/Out-File/Add-Content)
- 检查方法: scripts/gate_no_powershell_chinese.js

# GATE-6: 硬编码API Key/测试数据
- 强制等级: BLOCKER
- 门禁: 封装前扫描源码中sk-开头字符串、硬编码模型名、示例数据
- 检查方法: scripts/gate_no_hardcoded.js

# GATE-7: token/超时/深度限制
- 强制等级: BLOCKER
- 门禁: 扫描源码中token_budget/max_tokens<8192/timeout<30000/depth限制, 发现就BLOCKER
- 检查方法: scripts/gate_no_limits.js

# GATE-8: 数据持久化深拷贝问题
- 强制等级: BLOCKER
- 门禁: Vue 3用Pinia store统一数据源, 所有数据修改通过store action, action内自动调持久化。禁止直接修改store state
- 检查方法: 代码review检查是否有store.$state.xxx = yyy直接赋值

# GATE-9: 内存泄漏
- 强制等级: BLOCKER
- 门禁: Vue组件用onUnmounted清理所有定时器/事件监听器。标签页上限20个
- 检查方法: scripts/gate_memory_leak.js

# GATE-10: 降AI执行顺序
- 强制等级: BLOCKER
- 门禁: 顺序必须为S1到硬规则pre到S2到硬规则post。禁止硬规则在S1之前跑
- 检查方法: scripts/gate_deai_order.js

# GATE-11: 风格样本注入位置
- 强制等级: WARN
- 门禁: 风格样本注入S1(改写主力), S2不拿样本
- 检查方法: 代码review

# GATE-12: 正则误匹配
- 强制等级: BLOCKER
- 门禁: 所有正则匹配JSON的地方必须JSON.parse验证, match()调用必须有可选链
- 检查方法: scripts/gate_regex_safe.js

# GATE-13: reasoning_content未解析
- 强制等级: WARN
- 门禁: API响应解析同时检查content和reasoning_content字段
- 检查方法: 代码review

# GATE-14: 每轮新增规则不删旧规则
- 强制等级: WARN
- 门禁: 每次添加新GATE时审查所有现有GATE, 不适用的标记DEPRECATED。GATE总数控制在18条以内
- 检查方法: 人工审查

# GATE-15: 模态框卡死
- 强制等级: BLOCKER
- 门禁: Vue组件用v-if控制模态框显隐, 不用display:none/flex切换。组件卸载时自动清理
- 检查方法: 代码review

# GATE-16: Agent分派强制执行(新增)
- 强制等级: BLOCKER
- 门禁: 每个迁移阶段必须检查Agent分派表, 能并行的任务必须分派给不同Agent并行执行。禁止一个人串行做完所有任务
- 检查方法: 每波完成后审查是否所有标注为并行的Agent都实际被spawn了

# GATE-17: 防断网目标模式验证(新增)
- 强制等级: BLOCKER
- 门禁: 每波完成后验证防断网机制是否生效(模拟API中断, 检查是否自动重试+断点续跑)
- 检查方法: 人为中断API请求, 验证应用是否能从断点恢复而非从头重来

# GATE-18: 左边栏Agent进度可见验证(新增)
- 强制等级: BLOCKER
- 门禁: 每波完成后验证左边栏Agent进度面板是否正确显示: 运行中的Agent显示绿色、完成的显示蓝色、失败的显示红色
- 检查方法: spawn Agent后左边栏立即出现绿色条目, Agent完成后变蓝色
