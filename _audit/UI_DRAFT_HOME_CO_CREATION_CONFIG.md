# 主页编辑器共创配置 UI 审核稿 V3

日期：2026-09-03
状态：待用户审核（仅设计稿，未改应用源码）

## 需求记录

1. 主页聊天 API 链路与生成流水线配置彻底切断：主页使用自己的共创配置，两套配置独立保存、互不覆盖。
2. 复用大纲工作台的完整 SKILL/AGENT 协作经验：智能体、技能、串行/并行、已选技能、逐技能智能体、上下文记忆、断点与校验语义一致。
3. 共享逻辑，不复制代码：抽象成共享工作台能力，主页和大纲工作台共同调用，后续修复一次生效两处。

## V3 定稿方向

按用户手绘草图，配置条不再是 API 区域上方的独立大面板，而是紧贴在 API 对话框底部的附属两条小行：

1. 第一行：`SKILL选择 | AGENT | 模式 | 共创按钮`，三个内联选择器和右侧小按钮排在一行。
2. 第二行：`SKILL显示`，已选技能以小 chip 横排展示，包含序号、技能名、移除按钮，右侧保留 `+添加`。

这样配置区和对话区融为一体，不额外占用纵向大块空间，也不会把消息区和输入框挤出主视野。

## 设计说明

| 区域 | 目的 | 备注 |
|---|---|---|
| 对话消息区 | 与 AI 基于主页编辑器内容共创 | 保留现有插入、替换、预览、回滚能力 |
| 输入区 | 发送当前请求 | 沿用现有续生成、取消、重试、错误恢复 |
| 配置第一行 | SKILL、AGENT、模式三个内联选择器 + 右侧共创按钮 | 紧贴输入框下方，作为 API 对话框附属设置 |
| 配置第二行 | 已选技能执行顺序展示与移除 | 横向 chip，不占大面积；空间不足时收起并在技能面板中管理 |

## 关键交互

1. 配置独立保存：主页配置保存在 `coCreation` 配置域，不读写 `pipelineStore`。
2. 上下文来源：主页编辑器当前内容 + 最近 N 轮共创对话；不再自动读取流水线层 SKILL。
3. 修改写入：AI 只能通过现有编辑协议生成修改建议，用户确认后写入编辑器，可回滚。
4. 断点续跑：串行模式失败后保存具体失败 SKILL，恢复时从该 SKILL 继续。
5. 日志标识：诊断日志 `source` 使用 `HomeCoCreation.skill`，与流水线日志明确区分。
