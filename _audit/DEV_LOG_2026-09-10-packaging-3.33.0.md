# 2026-09-10 运行记录会话聚合封装（3.33.0）

## 开发功能

将「运行记录会话聚合」与同批次主页链路修复封装为 `3.33.0` 安装包。本包包含：

1. 大纲工作台与主页编辑器运行记录按会话聚合：同一连续对话形成一条记录，每次用户新请求作为独立轮次，时间线与 API 调用按轮次分组。
2. 手动封存：运行记录面板「导出/复制」Tab 提供「完成本段记录」，封存后下一条对话开启新会话。
3. 稳定落盘：chat 会话绑定会话开始时间戳命名，每轮结束即落盘，临时文件 + rename 原子替换。
4. 主页连续对话拆分根因修复：无编辑页签时会话键归一空字符串，避免 `'' === undefined` 导致每次新建 run。
5. 失败链路修复：未配置 API 提供方 / Key 的提前 return 复位生成状态；chat 会话不再被新 run 误标失败；reload 后恢复主页 chat run 指针。

## 交付目的

用户在大纲工作台或主页编辑器连续多轮调试 SKILL 时，不再需要复制或导出多条碎片记录；第三方 SKILL 制作方拿到一份 JSON 即可看到完整对话过程、每轮请求、API 调用、流式输出和诊断信息。
