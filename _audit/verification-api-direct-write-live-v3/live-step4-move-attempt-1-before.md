# 青石镇的雨季

## 第1节 雨落石桥
青石镇的雨从第1天开始变密，檐水沿着瓦当连成细线，落在巷口那块被踩得发亮的石板上。
沈萤把伞收在门后，账簿翻开第1页，纸页上还留着上一任渡口管事用朱笔圈出的数字：17。
她抬头看向窗外的运河，货船吃水很深，橹声被雨压得很低，像隔着几层湿布传来。
雨声敲在伞面上，像有人在很远的地方数着铜钱。这一句属于第1节，用来证明多轮直写不会误伤其他内容。
桥洞下停着三条空船，缆绳被水汽浸得发黑。这一句属于第1节，用来证明多轮直写不会误伤其他内容。
老周把门板卸下一半，用木棍撑住，站在门口看水位。这一句属于第1节，用来证明多轮直写不会误伤其他内容。
米铺的伙计挑着两袋米走过，鞋底踩进水洼又拔出来。这一句属于第1节，用来证明多轮直写不会误伤其他内容。
镇上的人说，这样的雨季里旧账最容易翻出来，因为水会把藏在木板缝里的字泡软。
