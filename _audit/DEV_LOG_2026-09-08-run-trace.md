# 开发日志：生成流水线运行记录（2026-09-08）

## 开发功能

将生成流水线顶栏“执行日志”升级为“运行记录”面板，为 SKILL 制作方提供一次生成任务的完整现场。

本次功能包含：

1. 新增 `src/stores/runTrace.ts`：按“次”记录运行，应用内保留最近 20 次；单次运行内部不限条数，完整保存请求消息、流式累计文本、返回全文、usage、folder SKILL 诊断与时间线事件。
2. `PipelinePanel.vue` 新增居中大面板：左侧运行列表，右侧详情四 Tab（时间线、API 调用、技能诊断、导出/复制）；详情文本区允许鼠标选中复制。
3. 四层生成入口（设定、卷纲、章节、正文）接入运行记录；除 `callApiWithAgent` 外，split-merge、multi-step、folder SKILL 引擎路径的 API 调用也写入同一次运行。
4. 新增 IPC `runTrace:export`：按次导出 JSON，主进程保存后同步写入应用数据目录 `run-trace/` 全量现场，避免应用内滚动窗口造成现场缺失。
5. 导出与复制双侧递归脱敏 API Key，供应商名称、地址、模型名保留，便于第三方定位配置问题。
6. 旧执行日志的点赞、点踩、优化建议、删除摘要继续可用，旧功能未被替换。

## 交付目的

让第三方 SKILL 制作方在用户不共享 API Key 的前提下拿到可调试的完整运行现场：提示词、滚动输出、返回原文、失败原因和技能诊断。用户可按次导出 JSON，或复制任意片段，用于反馈问题与迭代 SKILL。
