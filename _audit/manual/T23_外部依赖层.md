# T23 - 外部依赖层

## npm依赖

### 运行时依赖
1. hotkeys-js: 快捷键库
   - 用途: Ctrl+Z/Y/S等快捷键
   - 加载: <script src=node_modules/hotkeys-js/dist/hotkeys-js.min.js>
2. notyf: 通知库
   - 用途: Toast通知
   - 加载: <script src=node_modules/notyf/notyf.min.js> + CSS
3. marked: Markdown渲染库
   - 用途: 聊天消息Markdown转HTML
   - 加载: <script src=node_modules/marked/lib/marked.umd.js>

### 开发依赖
- electron: 桌面应用框架
- electron-builder: 打包工具

## 外部服务依赖

### 1. AI API服务(OpenAI兼容)
- 用户自行配置供应商(baseUrl + apiKey)
- 端点: /chat/completions(对话) + /models(模型列表)
- 兼容: OpenAI/Deepseek/CloudAI等

### 2. GitHub API
- 用途: 插件市场搜索仓库
- 端点: api.github.com/search/repositories
- 认证: Personal Access Token(public_repo权限)

### 3. 朱雀AI检测(可选)
- 用途: 去AI味效果验证(zhuque_check验证器)
- 端点: matrix.tencent.com/ai-detect
- 限制: 每日次数限制

## 文件系统依赖
- 数据目录: Documents/写作助手数据/
- 诊断日志: 同目录下diag文件
- 导出文件: 用户选择路径(对话框)
