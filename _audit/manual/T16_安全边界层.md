# T16 - 安全边界层 (Security Boundary Layer)

> 旧架构行为手册 第十六层 | 源码权威参考 | Vue3迁移差异检测驱动依据

## 1. 层级定位与职责边界

安全边界层负责应用的安全隔离、输入验证、XSS防护和敏感数据保护。作为Electron应用，安全模型依赖contextIsolation和preload桥接。

## 2. 进程隔离安全

### 2.1 contextIsolation

源码位置: main.js createWindow L72

contextIsolation: true 确保preload.js在隔离V8上下文运行，渲染进程JS无法直接修改preload注入的对象。

### 2.2 nodeIntegration禁用

nodeIntegration: false 禁止渲染进程使用require等Node.js API。所有Node.js能力只能通过preload暴露的IPC通道访问。

### 2.3 单实例锁

源码位置: main.js L43-55

app.requestSingleInstanceLock()防止多实例运行。第二实例启动时显示提示并退出，已有实例恢复焦点。

## 3. API Key保护

### 3.1 safeStorage加密

API Key使用Electron safeStorage API加密存储（见T08持久化层第5节）。加密绑定OS用户账户，换机器无法解密。加密不可用降级明文。

### 3.2 内存中明文

API Key在内存中始终明文（解密后），只在持久化时加密。这意味着内存dump可以获取明文Key。已知风险但旧架构未处理。

### 3.3 日志脱敏

ErrorLog和DiagLogger不主动记录API Key。但如果API请求失败时错误消息包含请求详情，可能间接暴露。旧架构没有显式的日志脱敏机制。

## 4. XSS防护

### 4.1 聊天消息v-html

聊天消息使用marked解析markdown后通过v-html注入DOM。marked输出不经过sanitize，如果AI响应包含恶意HTML/JS，可能导致XSS。

已知缺陷：没有使用DOMPurify或类似库对marked输出做sanitize。

### 4.2 编辑器contenteditable

编辑器使用contenteditable div，用户输入的HTML会被浏览器解析。如果粘贴恶意HTML可能执行脚本。旧架构没有对编辑器内容做sanitize。

### 4.3 innerHTML拼接

多处使用innerHTML拼接HTML（如章节列表、设置面板）。如果数据中包含用户输入的HTML字符（如< > "），可能导致XSS。旧架构部分位置使用textContent但不是全部。

## 5. 输入验证

### 5.1 IPC参数验证

IPC处理器不验证参数类型和内容。storage:read的key参数不验证格式，storage:write的data参数不验证大小。恶意渲染进程可以传入任意参数。

### 5.2 safeKey防护

main.js safeKey函数将key中非[a-zA-Z0-9_-]字符替换为下划线，防止路径遍历攻击（如../attempt）。

### 5.3 URL验证

baseUrl不验证格式，用户可以输入任意字符串。API请求时fetch会自然处理无效URL（抛出错误），但不防止SSRF。

## 6. 远程调试端口

源码位置: main.js L40

app.commandLine.appendSwitch("remote-debugging-port", "9223");

远程调试端口9223在开发环境有用但在生产环境是安全风险。任何能访问localhost:9223的进程可以调试应用。旧架构在生产构建中也启用此端口。

## 7. Vue3迁移差异检测要点

必须保留：contextIsolation: true；nodeIntegration: false；safeStorage加密；safeKey路径遍历防护；单实例锁。

必须修复：marked输出做XSS sanitize（用DOMPurify）；IPC参数验证；编辑器内容sanitize；远程调试端口生产环境关闭；日志脱敏。

差异检测规则：contextIsolation必须为true；nodeIntegration必须为false；safeStorage加密必须保持；safeKey正则必须保持。

## 8. 已知问题

1.marked输出无XSS防护（严重） 2.编辑器contenteditable无sanitize 3.IPC无参数验证 4.远程调试端口生产环境开启 5.无日志脱敏 6.内存中API Key明文
