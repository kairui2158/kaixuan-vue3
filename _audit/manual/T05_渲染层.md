# T05 - 渲染层行为手册

> 本文档深度分析旧架构中所有渲染机制、CSS设计令牌系统、主题切换、布局体系、组件视觉规格、动画过渡、响应式策略等行为契约，作为Vue3迁移的渲染层权威参考。

## 1. CSS文件架构

### 1.1 CSS文件清单

旧架构的CSS分为6个文件，在renderer.html中按序加载:

| 加载顺序 | 文件路径 | 大小 | 职责 |
|---|---|---|---|
| 1 | style.css | 7489行 | 主样式表，包含历史CSS和组件样式 |
| 2 | styles/components/app-layout.css | 5212字节 | 应用整体布局 |
| 3 | styles/tokens.css | 10847字节 | 设计令牌系统（唯一真相源）|
| 4 | styles/components/buttons.css | 13896字节 | 按钮组件样式 |
| 5 | styles/components/modal-panel.css | 7433字节 | 模态框和面板样式 |
| 6 | styles/components/form-editor.css | 24069字节 | 表单和编辑器样式 |

**加载顺序关键**: tokens.css 在 style.css 之后加载，因此 tokens.css 中的变量定义会覆盖 style.css 中的同名变量。

### 1.2 CSS变量来源问题

旧架构存在一个历史遗留问题：style.css 的 :root 块（L22-111）定义了一套设计令牌，但 tokens.css 的 :root 块也定义了一套完整的令牌。两者存在以下冲突:
- style.css :root 中的 --space-xxs=2px vs tokens.css :root 中的 --space-xxs=2px（一致）
- style.css :root 中的 --radius-sm=4px vs tokens.css :root 中的 --radius-sm=6px（冲突！tokens.css 覆盖）
- style.css :root 中的 --font-size-xs=10px vs tokens.css :root 中的 --font-size-xs=clamp(12px,0.72vw,13px)（冲突！）
- style.css :root 中的 --bg-primary 无定义（暗色主题在tokens.css中）vs tokens.css :root 中的 --bg-primary=#0a0a0c

**迁移注意**: Vue3 应统一使用 tokens.css 作为唯一令牌源，删除 style.css :root 中的重复定义

## 3. 主题系统

### 3.1 主题架构

**暗色主题（默认）**: 
- 定义在 tokens.css :root 中
- 通过 color-scheme: dark 声明
- 所有颜色变量直接在 :root 中定义

**亮色主题**:
- 定义在 style.css L778: `:root[data-theme="light"]`
- 覆盖暗色主题的颜色变量
- 颜色方案: #f5f5f7 背景, #1a1a1f 文本, #5b6bdb 强调色

### 3.2 主题切换机制

**源码位置**: renderer_v2.js

**_applyAppearance()** (L3111):
- 读取 settings.fontSize（默认14）和 settings.editorFontSize（默认15）
- 设置 CSS 变量: --font-size 和 --font-size-editor
- 直接设置编辑器元素 fontSize
- 切换 body 类: light-theme（亮色时添加）

**_toggleTheme()** (L5190):
- 读取当前 data-theme 属性（默认dark）
- 切换: dark ↔ light
- 设置 documentElement 的 data-theme 属性
- 持久化到 StorageManager.set("app-theme", next)
- 更新按钮文本: dark→☀, light→☾

**_loadTheme()** (L5201):
- 从 StorageManager.get("app-theme") 读取（默认dark）
- 设置 documentElement 的 data-theme 属性
- 更新按钮文本

**_saveAppearance()** (L3122):
- 读取表单值: cfg-font-size, cfg-editor-font-size, cfg-theme
- 保存到 settings 并调用 saveSettings()
- 调用 _applyAppearance() 应用

### 3.3 主题切换的行为契约

1. 主题切换是即时的，不需要刷新页面
2. 主题持久化在 StorageManager("app-theme")
3. 亮色主题通过 data-theme="light" 属性选择器覆盖变量
4. 暗色主题是默认值，不需要额外属性
5. 字体大小通过 CSS 变量动态设置，不依赖主题
6. _applyAppearance 和 _toggleTheme 是两套独立的主题管理逻辑:
   - _applyAppearance 读取 settings.theme 并切换 body.light-theme 类
   - _toggleTheme 读取 data-theme 属性并切换 documentElement.data-theme
   - 这两套逻辑不完全一致，可能导致主题状态不同步

**迁移注意**: Vue3 应统一为一套主题管理系统，使用 useTheme() composable + CSS变量

### 4.5 面板覆盖层

**覆盖机制**:
- 面板使用 position: fixed 或 absolute
- backdrop 背景使用 --bg-overlay (rgba(0,0,0,0.5))
- 面板使用 --bg-elevated 背景
- 面板过渡: --transition-panel (opacity 0.2s, transform 0.2s)

**面板显隐CSS模式**:
- 每个面板有一对CSS类: visible 和 hidden (如 ow-hidden/pl-hidden/sc-hidden/mem-hidden)
- visible 类显示面板，hidden 类隐藏面板
- 过渡通过 opacity 和 transform 实现

## 5. 动画与过渡系统

### 5.1 关键帧动画

| 动画名 | 定义 | 用途 |
|---|---|---|
| fadeIn | opacity 0→1, translateY 6px→0 | 消息气泡入场 |
| blink | opacity 1→0→1 (50% 0) | 流式光标闪烁 |
| dotPulse | opacity 0.3→1→0.3, scale 0.8→1→0.8 | 加载动画 |\n+
### 5.2 过渡应用场景

**按钮过渡**: --transition-button
- background-color, border-color, color 各 0.15s ease
- 悬停: --hover-lift (translateY(-1px))
- 按下: --hover-press (scale(0.97))

**面板过渡**: --transition-panel
- opacity 0.2s ease, transform 0.2s ease
- 面板打开: opacity 0→1, transform scale(0.95)→scale(1)

**卡片过渡**: --transition-card
- box-shadow 0.2s ease, border-color 0.2s ease, transform 0.2s ease
- 悬停: shadow-md + border-accent + hover-lift

**输入框过渡**: --transition-input
- border-color 0.15s ease, box-shadow 0.15s ease
- 焦点: border-accent + shadow-focus

### 6.2 渲染模式

旧架构使用**命令式渲染** (imperative rendering):
- 数据变更后手动调用 render*() 函数
- 使用 innerHTML 字符串拼接生成DOM
- 通过 getElementById + classList 操作DOM

**渲染函数模式示例**:
```javascript
renderSkillList() {
  var skills = SkillManager.getAll();
  var list = document.getElementById("skill-list");
  if (skills.length === 0) {
    list.innerHTML = "<p class='empty-hint'>暂无可用技能</p>";
    return;
  }
  var html = "";
  skills.forEach(function(s) {
    html += "<div class='skill-item'>...";
  });
  list.innerHTML = html;
  // 重新绑定事件（因为innerHTML清除了旧DOM）
}
```

**迁移注意**: Vue3 改为**声明式渲染** (declarative rendering):
- 使用 v-for 指令渲染列表
- 数据变更自动触发响应式更新
- 不需要手动调用 render*() 函数
- 不需要 innerHTML 字符串拼接

## 7. 响应式策略

### 7.1 字号响应式

旧架构使用 clamp() 实现字号响应式:
- --font-size: clamp(12px, 0.85vw, 16px)
- --font-size-sm: clamp(13px, 0.72vw, 14px)
- --font-size-lg: clamp(15px, 1.1vw, 20px)
- --font-size-editor: clamp(13px, 1vw, 18px)

**注意**: 用户曾明确要求"不要用viewport width缩放字体"，但tokens.css仍使用了clamp+vw。Vue3迁移时应改为固定字号。

### 7.2 面板布局响应式

- 章节概览面板: width=280px, 滑入滑出 (translateX)
- 仪表盘网格: grid-template-columns: repeat(auto-fit, minmax(180px, 1fr))
- 大纲工作台: 支持拖拽调整大小（最小400x300）

### 7.3 无viewport-based布局响应式

旧架构没有@media媒体查询来做布局响应式。整个应用是固定桌面布局，不适应移动端。

**迁移注意**: Vue3 应考虑添加@media断点，至少支持平板尺寸

## 10. 行为契约清单

1. **CSS变量唯一真相源**: tokens.css 是所有设计令牌的唯一来源，style.css :root 中的重复定义应被忽略
2. **暗色默认**: 应用默认暗色主题，亮色主题通过 data-theme="light" 属性切换
3. **主题持久化**: 主题选择保存在 StorageManager("app-theme")
4. **字体大小动态设置**: 字体大小通过CSS变量动态设置，不硬编码在CSS中
5. **命令式渲染**: 所有渲染函数手动调用，数据变更后需显式调用render函数
6. **innerHTML字符串拼接**: 列表渲染使用innerHTML拼接HTML字符串
7. **事件委托**: 渲染后的DOM通过事件委托(data-a属性)绑定交互
8. **面板CSS类管理**: 面板显隐通过添加/移除visible和hidden类实现
9. **过渡不使用var()**: transition简写中不使用CSS变量，用硬编码值
10. **字号clamp响应式**: 字号使用clamp+vw实现响应式（已知用户反对）

---

## 11. 迁移注意事项

1. **统一令牌源**: 删除style.css :root中的重复变量定义，tokens.css作为唯一来源
2. **命令式→响应式**: renderChapterTree等函数改为Vue3响应式数据绑定
3. **innerHTML→v-for**: 列表渲染改为v-for指令
4. **CSS类→v-show/v-if**: 面板的visible/hidden类改为v-show或条件渲染
5. **主题统一**: 合并_applyAppearance和_toggleTheme为一套useTheme() composable
6. **字号固定化**: 移除clamp+vw，改为用户可配置的固定字号
7. **Scoped CSS**: Vue3组件使用scoped CSS或CSS Modules
8. **滚动条**: 保持自定义滚动条或迁移到OverlayScrollbars
9. **过渡系统**: Vue3的<Transition>组件替代手动CSS类切换
10. **z-index管理**: 保持z-index令牌系统，避免层级冲突
11. **CSS变量传递**: Vue3中CSS变量通过:root或var()继续使用，可配合useCssVar()
12. **主题切换**: Vue3中可用useColorMode() (VueUse)或自实现useTheme()
13. **面板缩放**: 封装为usePanelResize() composable
14. **亮色主题补全**: style.css L778的亮色主题变量需与tokens.css完全对称

## 12. 已知缺陷与风险

1. **双重:root定义**: style.css和tokens.css都有:root块，变量冲突
2. **双重主题管理**: _applyAppearance用body类，_toggleTheme用data-theme属性，两套系统不统一
3. **clamp+vw字号**: 用户明确反对但仍在使用
4. **无媒体查询**: 不支持移动端/平板布局
5. **innerHTML XSS风险**: 使用innerHTML拼接用户内容可能存在XSS风险（有_escHtml函数但使用不一致）
6. **亮色主题不完整**: style.css L778的亮色主题可能缺少某些tokens.css中新增的变量
7. **transition var()陷阱**: tokens.css警告不要在transition简写中使用var()，但代码中可能仍有违反
8. **CSS文件分散**: 6个CSS文件，加载顺序依赖性强，容易出错
9. **style.css膨胀**: 7489行，包含大量历史遗留和注释掉的代码
10. **重复选择器**: style.css存在大量重复选择器定义（教训#2和#76）
