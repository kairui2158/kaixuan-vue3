# T14 - 应用级状态机 (Application State Machine)

> 旧架构行为手册 第十四层 | 源码权威参考 | Vue3迁移差异检测驱动依据

## 1. 层级定位与职责边界

应用级状态机管理面板切换、编辑模式、生成流水线阶段、去AI味流程状态等全局应用状态。旧架构没有正式的状态机库，状态通过全局变量和DOM操作隐式管理。

## 2. 面板状态管理

### 2.1 面板切换

旧架构通过overlay系统管理面板显示。每个面板（设置/去AI味/诊断日志等）是一个overlay，点击侧栏按钮显示对应overlay，点击backdrop隐藏。

状态变量：当前活跃的overlay ID。通过display: none/block控制显隐。

行为契约：同一时间只能有一个overlay活跃；点击backdrop关闭当前overlay；ESC键关闭当前overlay。

### 2.2 设置面板tab状态

设置面板有6个tab：API设置/技能/智能体/外观/去AI味/诊断日志。tab切换通过CSS active类控制。

### 2.3 侧栏面板状态

侧栏有7个按钮对应不同功能区域。点击按钮显示对应overlay，高亮当前按钮。

## 3. 编辑器状态

### 3.1 编辑模式

编辑器有两种模式：查看模式（只读）和编辑模式（可修改）。模式切换通过contenteditable属性。

### 3.2 撤销重做栈

使用document.execCommand('undo'/'redo')，浏览器自动管理撤销栈。应用不维护自定义撤销栈。

### 3.3 自动保存状态

自动保存通过setInterval定期触发。保存状态通过UI提示（如"已保存"/"保存中"）。

### 3.4 内容修改标记

编辑器内容被修改后标记为"未保存"，保存后清除标记。关闭时检查未保存状态决定是否显示退出确认。

## 4. 生成流水线状态

### 4.1 流水线阶段

生成流水线有5个阶段：大纲 -> 设定 -> 卷纲 -> 章节 -> 正文。每个阶段有独立的UI区域和SKILL调用。

阶段切换：用户手动点击侧栏按钮切换，或完成一个阶段后自动切换到下一阶段。

### 4.2 生成状态

每个阶段有3种状态：空闲（未生成）、生成中（API调用中）、已完成（有生成结果）。

生成中状态：禁用生成按钮、显示进度条、显示取消按钮。完成后：启用下一步操作。

### 4.3 断网续接状态

章节生成支持断网续接。状态：已生成章节数、总章节数、当前生成章节索引。续接时从断点继续。

## 5. 去AI味流程状态

### 5.1 流程阶段

去AI味流程状态：硬规则预处理 -> S1改写 -> 硬规则清洗 -> S2验证 -> 硬规则安全网。每个阶段有独立的进度百分比。

### 5.2 模式状态

三种模式：chain（串行链式）、split-merge（切分并行）、multi-step（多步代码控制）。模式选择影响流程执行路径。

### 5.3 进度状态

进度条显示当前步骤和总步骤的百分比。进度条有取消按钮可中断流程。

## 6. 聊天面板状态

聊天面板状态：消息列表、输入框内容、流式输出状态（是否正在生成）、当前活跃的SKILL。

流式输出状态：发送消息 -> 等待API响应 -> 流式接收 -> 完成/取消。

## 7. 状态同步机制

旧架构的状态同步主要靠：
1. 全局变量直接赋值
2. DOM操作反映状态变化
3. StorageManager持久化关键状态
4. 事件回调触发状态更新

没有响应式系统，状态变化不会自动传播到UI。需要手动调用渲染函数更新DOM。

## 8. Vue3迁移差异检测要点

必须保留：overlay显隐逻辑（同时只显示一个）；6个设置tab；5个流水线阶段；3种去AI味模式；断网续接状态；进度条取消功能；未保存内容检查。

可改进：用Pinia store集中管理状态；用Vue3响应式自动同步UI；用状态机库（如XState）管理复杂流程；用computed自动派生状态。

差异检测规则：面板同时只显示一个overlay必须保持；设置6个tab必须保持；流水线5阶段必须保持；去AI味3模式必须保持；断网续接必须保持。

## 9. 已知问题

1.状态分散在全局变量中无集中管理 2.状态变化需手动更新DOM 3.无状态机库复杂流程难维护 4.撤销重做依赖废弃API 5.多面板状态可能不同步
