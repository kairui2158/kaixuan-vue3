> 用途: Vue3迁移的行为规格权威参考 + 差异检测分类规则驱动依据

## 手册概述

本手册由23个独立维度层组成，每层从旧架构源码中提取行为契约（输入/输出/用户感知/状态变更），
作为Vue3迁移时逐层比对的行为规格基准。差异检测规则以每层的"Vue3迁移差异检测要点"章节为驱动。

## 使用方法

### 1. Vue3迁移对照
每层包含"Vue3迁移差异检测要点"章节，列出：
- 必须保留: 旧架构中必须原样迁移到Vue3的行为
- 必须修复: 旧架构中的已知缺陷，迁移时需修复
- 差异检测规则: 可自动化的检测规则，用于验证Vue3实现是否符合规格

### 2. 差异检测自动化
每层的"差异检测规则"可直接转化为自动化测试用例：
- 存在性检查: 某个函数/变量/配置项是否存在于Vue3代码中
- 行为一致性检查: 某个操作的输入输出是否与旧架构一致
- 状态一致性检查: 某个操作后的应用状态是否与旧架构一致

### 3. 逐层迁移顺序建议
推荐迁移顺序（依赖关系从底层到上层）：
1. T01数据层 -> T08持久化层 -> T13IPC边界层 -> T21主进程层
2. T12配置层 -> T16安全边界层 -> T17版本迁移层
3. T09网络层 -> T02调用链层 -> T20定时器与异步层
4. T05渲染层 -> T06事件层 -> T04交互流程层
5. T03功能系统层 -> T22数据流向层 -> T14状态机
6. T10错误处理 -> T11性能 -> T15编码文本
7. T18焦点无障碍 -> T19构建打包 -> T23外部依赖
8. T07生命周期（贯穿所有层）

## 已知跨层问题

1. **CSS层叠冲突** (T05/T11): style.css 7489行存在大量重复选择器，旧架构"只加不删"导致死代码
2. **XSS风险** (T05/T16): marked输出无sanitize，聊天消息v-html直接注入
3. **IPC无验证** (T13/T16): IPC参数无类型检查和内容验证
4. **无数据版本号** (T01/T08/T17): 存储数据没有版本字段，迁移依赖标记文件
5. **全局状态散落** (T14): 状态管理分散在多个全局变量，无集中管理
6. **远程调试端口** (T16/T19): 生产环境开启remote-debugging-port:9223
7. **AbortController散落** (T09/T20): 取消逻辑分散在各功能模块，无统一管理
