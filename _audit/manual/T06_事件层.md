# T06-事件层行为手册

> 本文档描述旧架构（renderer_v2.js + panels.js）中所有事件绑定、分发、委托、传播控制的完整行为规格。
> 作为Vue3迁移的行为契约参考和差异检测分类规则的驱动依据。

## 1. 事件绑定体系概览

旧架构使用三种事件绑定方式，每种有明确的使用场景和生命周期约束：

### 1.1 直接addEventListener绑定（主要方式）

在 `bindEvents()` 方法中集中绑定，覆盖应用90%以上的事件。特点：

- 在 `init()` 末尾调用 `this.bindEvents()`
- 所有绑定使用 `document.getElementById()` 获取元素
- 回调函数通过 `var self = this` 捕获this引用
- 每个元素只绑定一次，不重复绑定
- 不使用事件委托的元素直接绑定click/keydown/input等事件

源码位置：renderer_v2.js bindEvents() 方法，约200+个addEventListener调用

### 1.2 hotkeys-js库绑定（快捷键专用）

用于全局快捷键，独立于addEventListener体系。特点：

- 在bindEvents()末尾设置 `hotkeys.filter = function(){ return true; }` 覆盖默认过滤器
- 所有快捷键通过hotkeys()函数注册
- 快捷键回调内调用e.preventDefault()阻止浏览器默认行为
- 支持ctrl/command双平台修饰键

注册的快捷键列表：
- escape: 关闭查找栏或所有模态框
- ctrl+f/command+f: 打开查找替换栏
- ctrl+s/command+s: 手动保存
- ctrl+shift+n/command+shift+n: 新建项目表单
- ctrl+shift+p/command+shift+p: 打开项目列表
- ctrl+k/command+k: 清空聊天

### 1.3 HTML内联onclick绑定（面板管理专用）

panels.js中的面板HTML模板使用内联onclick属性。特点：

- onclick调用全局window._app的方法
- 面板HTML通过innerHTML动态插入，内联事件随HTML一起渲染
- 不需要额外addEventListener
- 面板关闭时HTML被移除，事件自动销毁

## 2. 全局键盘事件（init阶段）

### 2.1 init()中的keydown监听器

在init()方法开头注册全局keydown监听器，处理核心快捷键：

```javascript
document.addEventListener("keydown", function(e) {
  if (e.key === "Escape") { self.closeAllPanels(); return; }
  if (e.ctrlKey || e.metaKey) {
    if (e.key === "1") { e.preventDefault(); self.openOutlineWorkspace(); }
    else if (e.key === "2") { e.preventDefault(); self.showSettingsCollection(); }
    else if (e.key === "3") { e.preventDefault(); self.showPipeline(); }
    else if (e.key === "4") { e.preventDefault(); self.showMemory(); }
    else if (e.key === "5") { e.preventDefault(); self.showPluginMarket(); }
    else if (e.key === ",") { e.preventDefault(); self.toggleSettings(true); }
    if (e.key === "z") { e.preventDefault(); self._undo(); }
    else if (e.key === "y") { e.preventDefault(); self._redo(); }
    else if (e.key === "s") { e.preventDefault(); self.saveEditorContent(); }
  }
});
```

### 2.2 与hotkeys-js的分工

init()中的keydown监听器处理数字键导航（Ctrl+1-5）和基础编辑操作（Ctrl+Z/Y/S）。
hotkeys-js处理查找、保存、新建项目、项目列表、清空聊天等更复杂的快捷键。
两者不冲突，因为处理的键不同。

### 2.3 Escape键的优先级逻辑

Escape键有优先级处理：
1. 先检查查找替换栏是否可见 -> 关闭查找栏
2. 否则依次关闭所有模态框（设置、项目、设置集合、记忆、流水线、新项目、卷编辑、技能绑定、SC绑定）
3. 每个关闭操作都包裹在try-catch中，防止单个关闭失败影响其他

## 4. 面板内事件绑定模式

### 4.1 onclick覆盖式绑定（panels.js）

panels.js中的面板HTML模板使用内联onclick属性：

```html
<button onclick="window._app.someMethod('param')">按钮</button>
```

这种方式的特点：
- 面板HTML通过innerHTML动态插入
- 内联事件随HTML一起渲染，不需要额外addEventListener
- 面板关闭时HTML被移除，事件自动销毁
- 所有调用通过window._app全局引用

### 4.2 大纲工作台面板

大纲工作台是panels.js中最复杂的面板，包含：
- 文件导入按钮（onclick -> openFileImporter）
- DOCX解析按钮（onclick -> parseDocxFile）
- AI共创按钮（onclick -> startAiCollaboration）
- 锁定大纲按钮（onclick -> lockOutline）
- 大纲编辑区域（contenteditable）

### 4.3 面板缩放事件

面板支持拖拽缩放，通过_initPanelResizers()初始化：
- mousedown开始拖拽
- mousemove调整面板宽度/高度
- mouseup结束拖拽
- 缩放过程中preventDefault防止文本选中

## 5. IPC事件

### 5.1 onFinalSave（退出前保存）

```javascript
window.electronAPI.onFinalSave(function() {
  selfRef.autoSave();
  selfRef._syncTreeToPipeline();
  var _pl = selfRef._plData(); if (_pl) selfRef._plPersist(_pl);
  StorageManager.set("lastSession", {...});
  selfRef._lastSaveTime = Date.now();
});
```

每个操作都包裹在try-catch中，防止一个失败影响其他。失败时输出console.warn + DiagLogger.warn。

### 5.2 onCloseRequest（关闭请求）

```javascript
window.electronAPI.onCloseRequest(function() {
  var modal = document.getElementById("exit-confirm-modal");
  modal.classList.remove("modal-hidden");
  modal.classList.add("visible");
});
```

显示自定义退出确认模态框（非浏览器原生confirm）。

### 5.3 退出确认按钮事件

- btn-exit-save click -> respondCloseChoice(0)（保存后退出）
- btn-exit-direct click -> respondCloseChoice(1)（直接退出）
- btn-exit-cancel click -> respondCloseChoice(2)（取消退出）
- exit-close（×按钮）click -> respondCloseChoice(2)（同取消）

### 5.4 文件操作IPC

通过window.electronAPI调用的文件操作：
- dialogSaveFile(savePath): 保存文件对话框
- dialogOpenFile(): 打开文件对话框
- storageExport(path): 导出数据到文件
- storageImport(path): 从文件导入数据

所有IPC调用前检查window.electronAPI是否存在。

## 6. 事件传播控制

### 6.1 stopPropagation使用场景

- 章节树del-ch按钮：e.stopPropagation()防止触发tree-body的点击事件
- 双击重命名：e.stopPropagation()防止触发其他双击行为
- 右键菜单：不stopPropagation，通过document click关闭

### 6.2 preventDefault使用场景

- 所有Ctrl/Cmd快捷键：preventDefault阻止浏览器默认行为
- 拖拽dragover：preventDefault允许drop
- 拖拽drop：preventDefault阻止默认拖拽行为
- Enter发送消息：preventDefault阻止换行
- hotkeys回调：preventDefault阻止快捷键默认行为

### 6.3 事件冒泡链

典型的点击事件冒泡链：
1. 用户点击章节树内的按钮
2. 事件冒泡到tree-body
3. tree-body的click监听器通过closest找到[data-a]按钮
4. 根据data-a值分发到对应方法
5. del-ch按钮的stopPropagation阻止继续冒泡

## 7. 事件委托模式总结

旧架构大量使用事件委托模式，主要集中在以下容器：

| 容器元素 | 事件类型 | 委托选择器 | 动作数量 |
|----------|---------|-----------|--------|
| messages-list | click | .msg-btn | 3 |
| tree-body | click | [data-a] | 10 |
| tree-body | contextmenu | - | 1 |
| tree-body | dblclick | [data-a='open-ch'] | 1 |
| project-list | click | [data-a] | 2 |
| skill-list | click | [data-a] | 3 |
| agent-list | click | [data-a] | 4 |
| export-dropdown | click | [data-format] | N |
| ctx-menu | click | [data-a] | 3 |

事件委托的优势在旧架构中体现为：
- 动态添加的列表项不需要重新绑定事件
- 减少addEventListener调用数量
- 集中管理事件分发逻辑

## 9. 迁移注意事项

| 编号 | 注意事项 | Vue3对应方案 |
|------|---------|-------------|
| M-01 | bindEvents()中200+个addEventListener需迁移到Vue模板@事件 | 使用Vue的@click/@keydown/@input等指令 |
| M-02 | var self = this模式不需要 | Vue组件方法自动绑定this |
| M-03 | 事件委托模式可用Vue的组件化替代 | 列表项作为子组件，事件直接绑定在子组件上 |
| M-04 | hotkeys-js可在Vue中继续使用，或迁移到Vue自定义指令 | 可保留hotkeys-js，在mounted中注册 |
| M-05 | 内联onclick的panels.js面板需重构为Vue组件 | 每个面板作为独立Vue组件 |
| M-06 | document全局事件（mousedown关闭菜单）需在mounted注册，beforeUnmount清理 | 使用onMounted/onUnmounted生命周期 |
| M-07 | IPC事件监听需在mounted注册，beforeUnmount清理 | 同上 |
| M-08 | 拖拽排序逻辑可迁移到Vue Drag-and-Drop指令或库 | 考虑vuedraggable库 |
| M-09 | contenteditable重命名可迁移到Vue的v-model + contenteditable指令 | 自定义指令封装contenteditable |
| M-10 | exit-confirm模态框可迁移到Vue组件 + 状态控制 | 使用v-if控制显示 |
| M-11 | 右键菜单可迁移到Vue组件 + 坐标定位 | 使用绝对定位的Vue组件 |
| M-12 | 内联AI菜单可迁移到Vue组件 + 选区检测 | 使用window.getSelection() API |
| M-13 | _formDirty标记可迁移到Vue的watch或computed | 使用ref + watch |
| M-14 | 面板缩放可迁移到Vue自定义指令 | 使用指令封装mousedown/mousemove/mouseup |
| M-15 | 全局快捷键需确保在所有组件中可用 | 在App.vue根组件注册或使用插件 |

## 10. 已知缺陷与风险

| 编号 | 缺陷描述 | 风险等级 | 影响 |
|------|---------|---------|------|
| D-01 | document.execCommand("selectAll")已废弃 | 中 | 重命名功能可能在未来浏览器版本失效 |

| D-03 | model-select注册了两个change事件监听器 | 低 | 代码冗余，不影响功能但增加维护难度 |
