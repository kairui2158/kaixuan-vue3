# T22 - 数据流向层

## 核心数据流

### 1. 聊天数据流
```
用户输入 -> sendMessage() -> 构建messages(历史+Skill+Agent) -> _aiRequest(stream) -> SSE chunks -> onChunk更新DOM -> chatHistory.push -> 渲染messages-list
```

### 2. 流水线数据流
```
Step1大纲: textarea -> 确认 -> 保存到project
Step2设定: AI生成 -> pl-settings-result -> 保存到设定合集
Step3卷纲: AI生成 -> pl-volume-cards -> 确认 -> 写入chapters结构
Step4章节: AI生成 -> pl-chapter-cards -> 确认 -> 写入chapters结构
Step5正文: AI生成 -> pl-body-result -> 插入编辑器/保存到chapter
```

### 3. 去AI味数据流
```
editor文本 -> deAiProcess() ->
  硬规则pre(全量20条) ->
  分支:
    chain: S1(改写) -> S2(验证) -> ...
    splitMerge: 切分 -> Promise.all并行重述 -> 拼接
    multiStep: Step1(事件核) -> Step2(视角偏转) -> Step3(重组) -> S2
  -> 硬规则post(安全子集) ->
  -> 验证器(first_subject_different + cross_model_check) ->
  -> 写回editor / diff-modal
```

### 4. 设置数据流
```
表单input -> _formDirty=true -> 保存按钮 -> saveSettingsFromForm() -> 加密apiKey -> StorageManager.set -> 刷新UI
```

### 5. 章节数据流
```
tree-body click -> openChapter(vid,cid) -> ChapterManager.get -> editor加载内容 -> 修改 -> autoSave -> StorageManager.set
```

### 6. 持久化数据流
```
App数据 -> StorageManager.set(key, value) -> IPC storageWrite -> 主进程fs.writeFileSync -> {key}.json文件
{key}.json文件 -> 主进程fs.readFileSync -> IPC storageRead -> StorageManager.get(key) -> JSON.parse -> App数据
```

## 跨层数据传递
- Skill -> AI调用: SkillManager.getActiveSkills()返回template -> 拼接到messages
- Agent -> AI调用: AgentManager.get(id) -> model + temperature + systemPrompt
- Provider -> AI调用: ProviderManager -> baseUrl + apiKey(解密)
- Pipeline -> Chapter: 确认章节 -> ChapterManager.add -> 章节树渲染
- 设定 -> 卷纲: 设定合集数据作为卷纲生成的上下文
- 卷纲 -> 章节: 卷纲outline作为章节生成的输入
- 章节 -> 正文: 章节plot作为正文生成的输入

## 迁移注意
1. Vue3用Pinia store管理数据流
2. 跨层数据用store actions传递
3. 持久化用pinia-plugin-persistedstate
4. AI调用数据流封装到apiService composable
