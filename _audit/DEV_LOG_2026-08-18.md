## 设定层按钮语义与行为等价修复

### 目标

按用户确认的设定层图和行为语义，恢复 Vue3 新架构的单一闭环：

```text
已确认大纲
  -> AI设定生成
  -> 当前 Agent + SKILL 调用 API
  -> 提取设定并动态分配分类
  -> 用户编辑/绑定/确认分类
  -> 确认/保存设定层
  -> 设定层点亮并进入卷纲层
```

“连通大纲层”“根据 API 和 SKILL 扫描大纲”“保存所有设定”“点亮设定层”均是按钮效果，不是额外按钮。

### 实施

1. 删除 `btn-pl-link-settings-outline`，不再把“连通大纲层并分配分类”单独暴露为按钮。
2. 删除 `btn-pl-save-settings`，将保存职责并入唯一的 `btn-pl-confirm-settings`。
3. 将确认按钮改为“确认/保存设定层”，调用 `confirmSettingsLayer`：先保存当前项目，再执行设定层确认和进入卷纲。
4. `genSettings` 和按钮入口同时要求大纲已存在且已锁定，提示明确读取“已确认大纲”；分类仍由 API/SKILL 输出的 `category` 动态创建。
5. 未修改卷纲、章节、正文层业务逻辑。
