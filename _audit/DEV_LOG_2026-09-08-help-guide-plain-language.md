# 开发日志：帮助指南大白话教学更新

日期：2026-09-08  
版本：3.28.2（未重新封装）

## 需求

用户要求把应用内“帮助”教学指南更新成更详细、大白话的教学内容，并特别讲清 Folder SKILL 的导入规则：文件夹技能不需要先放入应用指定目录，可以直接从电脑任意位置导入。

## 修改内容

文件：`src/components/common/HelpGuide.vue`

1. 快速上手：用“小说加工流水线”解释整体流程，新增第一次使用的 8 步路径和三条最容易被忽略的规则。
2. 主界面：按“左边管目录、中间改文字、右边和 AI 讨论”重讲布局，并补充常用小动作。
3. 大纲工作台：补齐导入、AI 共创、保存、锁定、配置隔离的解释。
4. 生成流水线：逐层解释职责，说明大纲层配置已迁至工作台，并补进度条、逐卷生成、常见卡点。
5. 新增“技能与 Folder SKILL”章节：解释四种导入方式、Folder SKILL 结构、外部路径模式、路径失效恢复和只读展示。
6. 记忆板块：改成“AI 的项目记事本”，补记忆预览审核、拒绝、锁定、合并/覆盖导入风险。
7. AI 与配置：改为供应商、智能体、技能三层解释，技能模式改为“串行/并行”，排查步骤改成编号清单。
8. 去AI味：说明正文层已内嵌降AI，手动按钮的使用场景和检查点。
9. AI 命名、插件市场：改成更直接的大白话说明。
10. 新增“多窗口”章节：讲新建窗口入口、同项目禁止多窗口、全局配置共享和窗口状态恢复。
11. 外观设置：补主题两档、密度三档、字体作用范围、自动保存间隔。
12. 数据与诊断：补自动保存、导入导出、崩溃恢复横幅、数据目录、诊断日志和排查顺序。

## 用途

帮助新用户不需要外部文档就能理解应用的工作流、配置关系和 Folder SKILL 的真实导入方式，降低误操作与咨询成本。

- 文案与真实入口对账：技能导入四按钮、窗口菜单、密度三档、主题两档、诊断日志功能、崩溃恢复横幅、Folder SKILL 路径失效恢复按钮均来自当前源码。
