# 开发日志：大纲工作台与主页编辑器重置对话（2026-09-08）

## 开发功能

在大纲工作台 AI 共创对话框与主页编辑器 API 对话框各新增“重置对话”按钮，用于在对话跑偏且无法纠正时一次性清空当前对话与上下文，让 API 下次请求从当前编辑器内容重新开始。

1. `ChatPanel.vue`：发送按钮右侧新增“重置对话”按钮（`btn-reset-conversation`），生成中禁用；确认后清空 `chatStore` 当前会话消息，并调用 `conversationContextService.clearSession({ workspace: 'main' })` 清空主页上下文。
2. `OutlineWorkspace.vue`：输入区新增“重置对话”按钮（`btn-ow-reset-conversation`），生成中禁用；确认后清空 `projectStore.outlineChat`，并清空 `workspace: 'outline'` 上下文。
3. 两处均使用危险确认弹窗，文案明确说明影响范围：清空对话与会话上下文；不影响编辑器内容、项目记忆和运行记录。
4. 清空成功后在对话框显示提示：上下文已重置，API 将从当前编辑器内容/当前大纲重新开始。
5. 只清当前作用域（projectId + workspace + purpose），不影响其他项目、其他工作台或流水线上下文。

## 交付目的

解决用户反馈“和 API 聊着聊着跑偏，怎么纠正都纠正不回来”的问题。模型没有跨请求后台记忆，跑偏来自应用每次把历史消息继续打包进请求；本功能让用户一键把对话拉回初始状态。
