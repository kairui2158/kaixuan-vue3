# 神意 UI 视觉修复计划 V1

## 我的理解偏差根因

### 偏差1: 把统一理解成变量名统一
- 我做的: 458处 px 替换成 var() 但值不变
- 用户期望: 按钮位置合理、卡片大小一致、内容不拥挤
- 纠正: UI统一 = 用户视觉感知一致且合理

### 偏差2: 验证标准错误
- 我做的: CDP检查字号数值一致(12px=12px PASS)
- 用户期望: 截图对比确认按钮位置/卡片高度/内容间距
- 纠正: 验证 = 截图对比修前修后 + computedStyle

### 偏差3: 跳过视觉问题做基础设施
- 我做的: 先做token标准化没写修按钮位置
- 用户期望: 先修能看到的问题
- 纠正: 用户报告的问题优先级最高

## 防止再犯硬约束
1. 每修一个视觉问题必须CDP截图修前修后对比
2. 验证标准 = 用户眼睛能看到的变化
3. 修复顺序 = 用户报告的问题优先
4. 禁止用构建通过代替视觉正确
5. 禁止用token一致代替视觉一致
6. 每个修复必须读取实际CSS计算值确认

## 三个已知问题精准修复

### 问题1: 生成流水线关闭按钮居中
- 文件: PipelinePanel.vue
- 根因: .pl-header用space-between 4个子元素均匀分布
- 修复: header分左右两组 标题左 关闭+功能按钮用div包裹靠右
- 验证: CDP截图确认关闭按钮在右上角

### 问题2: 供应商卡片大小不一致
- 文件: ApiSettings.vue
- 根因: 有min-width无min-height 有模型列表的高没有的矮
- 修复: 加min-height 用grid替代flex让卡片等高
- 验证: CDP截图确认所有卡片高度一致

### 问题3: 去AI味卡片拥挤
- 文件: DeAiModeCard.vue
- 根因: padding 16px gap 8px margin-bottom 8px 太紧
- 修复: padding 20px gap 12px margin-bottom 12px
- 验证: CDP截图确认内容有呼吸空间

## 执行顺序
1. 修问题1流水线关闭按钮 截图验证
2. 修问题2供应商卡片等高 截图验证
3. 修问题3去AI味卡片松散 截图验证
4. 全应用CDP截图扫描发现其他视觉问题
5. 逐个修复发现的问题每个截图验证
6. 构建验证 更新经验总结 更新开发日志 GitHub推送
