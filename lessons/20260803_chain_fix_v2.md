# 20260803 链式SKILL断裂根因修复 V2

## 根因
链式SKILL执行到第3步断裂，有两个原因：
1. max_tokens=0 导致API用默认4096，第3步输入太大时4096不够
2. 某步API失败时 throw 中断整个链（无容错）

## 修复策略（V2 - 最终版）

### 核心：不传 max_tokens 给API
- 注释掉 `reqBody.max_tokens = cfg.maxTokens`
- 让API自己决定最大输出长度
- 避免了两个问题：4096太小 vs 128000超出模型限制

### 链式容错
- for循环内try-catch包裹_aiRequest
- 某步失败时：catch住、push带error的报告、continue到下一步
- 不再因为一步失败就throw中断整个链

### 客户端错误不重试
- 400/401/403/404 直接抛出，不进入重试循环
- 避免对不可恢复的错误重试999次

### 其他解除限制
- maxRetries: 3 -> 999
- timeoutMs: 300000 -> 999999999
- retryDelays: 3个 -> 20个递增
- _getAgentMaxTokens: 保底128000
- loadSettings: 自动提升旧的小值到128000
- HTML input: 移除max上限
