## 三、尝试过的全部路径

### 路径A：减法（删除）- 最先走的路

| 规则 | 操作 | 验证结果 | 评价 |
|------|------|----------|------|
| CLICHES | 删除/替换AI套话 | 词级，对结构无影响 | 轻微有效，但不是主杠杆 |
| rn3 (reduceSensoryDensity) | 删除1/2感官描写 | 降低密度但不改变结构 | 有效但有限 |
| rn7 (deleteEmptyOpenings) | 删除空泛开头 | 移除AI式背景铺垫 | 有效 |
| rn15 (selectDeleteExplanation) | 删除解释性叙述 | 移除太完整模式 | 有效 |
| r6 (removeParagraphSummaries) | 删除段落总结句 | 移除每段都总结模式 | 有效 |
| N38 (removeNarrationConclusions) | 删除叙述结论句 | 类似r6 | 有效 |
| N39 (removePreDialogueMicroExpression) | 删除对话前微表情 | 减少对话动作标签 | 轻微有效 |
| N40 (thinDialogueConditionals) | 截断对话条件链 | 减少对话完整性 | 轻微有效 |
| N37 (trimCompleteDialogue) | 削减过于完整的对话 | 减少对话完整性 | 轻微有效 |
| N13 (deleteSentences) | 句子删除 | 有害，禁用 | 失败 |
| N17 (deleteEnvironment) | 删环境描写 | 100%，有害，禁用 | 失败 |

减法小结：减法是探索最多的路径。删除冗余信息有效，但删除到一定程度后效果递减。本质是减少AI特征，不是增加人类特征。

### 路径B：改法（修改/重组）

| 规则 | 操作 | 验证结果 | 评价 |
|------|------|----------|------|
| rn2 (mergeShortSentences) | 合并所有<25字短句 | 创造长句(42-78字)，打破AI句式模式 | 主杠杆之一 |
| N30 (createParagraphRhythmVariation) | 段落节奏重组[2,1,3,1,4,1,2...] | 改变段落结构 | 主杠杆之一 |
| rn1 (dropSentenceStartPronoun) | 删除句首他 | 移除重复主语模式 | 有效 |
| rn4 (dropSentenceStartNames) | 删除句首人名 | 移除人名重复模式 | 有效 |
| rn9 (shuffleListingPattern) | 打散列举模式 | 改变信息顺序 | 有效 |
| rn10 (breakParagraphUniformity) | 修复段落趋同 | 打破重复结构 | 有效 |
| rn11 (fixUniformSentenceLength) | 修复句长趋同 | 创造长度变化 | 有效 |
| N41 (createDialogueWeightVariation) | 对话轮次轻重变化 | 改变对话节奏 | 轻微有效 |
| CONNECTOR_REPLACE | 替换连接词（非删除） | 改变表面但不改结构 | 轻微有效 |
| r2 (fixParagraphStartPeriods) | 修正段首句号 | 结构修正 | 有效 |
| N23 (reorderSentencesInParagraph) | 段落内句子重排 | 80%->100%，有害，禁用 | 失败 |
| N22 (varySentenceEndPunctuation) | 变换句尾标点 | 100%，有害，禁用 | 失败 |
| N14 (aggressiveSplitSentences) | 激进断句 | 有害，禁用 | 失败 |
| N21 (truncate) | 截断叙述 | 89.6%，有害，禁用 | 失败 |
| N20 (reorderSentences) | 句子重排 | 100%，有害，禁用 | 失败 |

改法小结：合并短句（rn2）和段落重组（N30）是两大主杠杆。但句子重排（N23/N20）全部失败——机械重排破坏可读性且产生新的AI信号。改法的有效区域是改变结构节奏，不是打乱信息顺序。

### 路径C：加法（增加文本）- 最少走的路

| 规则 | 操作 | 验证结果 | 评价 |
|------|------|----------|------|
| N27 (repeatVerbFragment) | 重复句尾动词碎片 | 80%->100%，有害，禁用 | 失败 |
| N18 (addTemplate) | 添加模板短语 | 100%，有害，禁用 | 失败 |

加法小结：这是走得最少的路，而且两次尝试都失败了。原因：机械添加的文本本身带有AI特征。方法论说加入具体经历和保留个人判断，但这些需要语义理解，硬规则无法生成上下文相关的新内容。

### 路径D：结构破坏（V16 bug效应）

| 尝试 | 操作 | 验证结果 | 评价 |
|------|------|----------|------|
| V16 bug | N30在r2/r6/r7之前运行，换行被覆盖后完全重组 | 科幻11.2%，古风19.5% | 意外有效 |
| V42 pre-flatten | 模拟V16 bug：先压平段落再重组 | 科幻24.5%，古风30.6%（无变化） | 失败 |

结构破坏小结：V16的低分来自一个意外bug——段落结构被完全破坏后再重组。V42试图用pre-flatten重现这个效果，但自检指标与V41完全相同，朱雀验证也无变化。V16的低分可能来自更复杂的因素组合，不是单一段落压平能复现的。

## 六、每条路的对错分析

### 对的（验证有效）
1. 结构修改是主杠杆（V39->V41降幅26.7%）
2. 合并短句创造长句模式（rn2 V41激进模式）
3. 段落节奏重组（N30）
4. 删除段落总结句和解释性叙述（r6/N15）
5. 删除句首代词/人名（rn1/rn4）
6. 替换（非删除）连接词（CONNECTOR_REPLACE）
7. 对话专项规则（N39/N40/N41）对对话结构有轻微改善

### 错的（验证失败或有害）
1. V37修复结构规则 → 方向性错误，减弱了最有效的杠杆
2. N27/N18机械添加文本 → 添加的内容本身是AI信号
3. N23/N20句子重排 → 破坏可读性，产生新AI信号
4. N22标点变化 → 人为制造模式
5. N14激进断句 → 短句过多=新AI信号
6. V42 pre-flatten → 无法复现V16 bug效果
7. 只走减法一条路 → 天花板24.5%，加法这条路没有成功走过

### 还没走的路
1. 加法的正确实现：不是机械添加，而是从原文中提取信息进行重组/扩展
   - 例如：把后文的信息提前到动作链中（信息前置）
   - 例如：重复前文的关键词（不是模板，是上下文相关的）
   - 例如：在动作链中插入环境碎片（从原文其他位置提取）
2. 改法的深层应用：不是句子重排，而是信息重组
   - 例如：把因果链改为先果后因
   - 例如：把完整叙述改为碎片化呈现
3. SKILL prompt层与硬规则层的配合
   - 硬规则处理结构（已验证有效到24.5%）
   - SKILL prompt处理内容（对话逻辑、具体经历、个人判断）

## 七、关键数据解读

### 为什么V16=11.2%而V41=24.5%？
- V16有一个bug：N30在r2/r6/r7/r8seq之前运行
- 这些规则用split(换行)处理文本，破坏了N30创建的双换行段落分隔
- 结果：所有段落被压成单换行分隔，然后N30重新用双换行分组
- 这产生了比V41更混乱、更不可预测的段落结构
- V42试图用pre-flatten重现这个效果，但失败了
- 可能原因：V16的bug不是简单的压平再重组，而是多个规则交互产生的复杂效果
- 也可能原因：V16测试时朱雀检测算法有变化，或文本有差异

### 为什么对话文本始终100%？
- 朱雀分段数据：对话部分77.18%被判AI
- 对话的AI特征不在结构，在内容逻辑
- 角色说话时会把原因、推理和结论全部说完 → 这是语义层面的问题
- 硬规则可以删除/截断对话的一部分，但不能改变对话的逻辑完整性
- N37/N40/N41只能做表面修剪，无法改变对话太完整的本质

### 科幻V42的AI信号在哪里？
- Segment 2（连续动作链）被判AI
- 特征：动作动词密集、因果链完整、无注意力漂移
- 这段是太线性、太完整的典型
- 要降低这段的AI率，需要打破因果链的流畅性或插入非序列信息
- 但这需要语义理解，硬规则做不到

## 八、下一步方向

### 方向1：加法的正确实现（探索未走完的路）
方法论反复强调加入具体经历、保留个人判断、有详有略。这些都是加法。但N27/N18失败说明机械添加不行。

可能的正确加法：
- 从原文其他位置提取信息，插入到动作链中（信息前置/后置）
- 把后文的描述提前到动作进行时（打破线性叙事）
- 重复前文的关键词或意象（增加回环感，非模板化）

这些操作不生成新文本，只是重新分配原文已有信息的出现位置。

### 方向2：SKILL prompt层配合
- 硬规则层处理结构（已验证到24.5%）
- SKILL prompt层处理内容（对话逻辑、具体经历、个人判断）
- 两层配合：硬规则做减法和结构改，SKILL prompt做加法和内容改

### 方向3：回到V16寻找答案
- V16的11.2%是所有版本中最低的
- pre-flatten无法复现，说明V16的低分来自更复杂的因素
- 可能需要重新审视V16的完整规则执行顺序和交互效应

### 方向4：接受硬规则的天花板
- 叙述类文本：V41配置已达24.5%（科幻）/30.6%（古风）
- 对话类文本：硬规则无法处理，需SKILL prompt层
- 硬规则做到这一步已经完成了它的使命——把容易的部分处理掉
- 剩下的难的部分（对话内容、连续动作链的线性叙事）需要模型层面的理解

## 九、总结

### 硬规则能做到的
1. 结构重组（段落节奏、句长变化）→ 主杠杆，V41=24.5%
2. 减法（删除冗余、删除总结、删除解释）→ 有效但有限
3. 表面替换（套话、连接词）→ 轻微有效
4. 对话结构修剪（截断、轻重变化）→ 对叙述类轻微有效，对对话类无效

### 硬规则做不到的
1. 加法（添加上下文相关的新内容）→ 机械添加=新AI信号
2. 对话内容重构 → 需要理解角色意图
3. 用具体替代抽象 → 需要生成新文本
4. 个人判断加入 → 需要语义理解
5. 打破连续动作链的线性叙事 → 需要理解叙事逻辑

### 核心教训
1. 减法走得最远但天花板有限（24.5%）
2. 改法中只有结构重组有效，句子重排全部失败
3. 加法几乎没有成功过——这是最大的未完成路径
4. V16的11.2%可能来自复杂的规则交互，不是单一因素
5. 对话类文本的100%是硬规则的硬天花板
6. 用户说的有减有加有改是对的——我只走了减法和改法，加法这条路还没有真正走通

### 方法论理解程度：75%
- 结构层面：理解透彻，验证充分
- 减法层面：理解透彻，验证充分
- 加法层面：理解方向但实现失败，需要重新思考
- 对话层面：理解问题但无法解决
- 整体：方法论的核心逻辑已经验证，但加法这条路的正确实现方式还没找到
