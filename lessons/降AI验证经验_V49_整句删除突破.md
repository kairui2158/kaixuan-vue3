# 降AI验证经验 V49 — 整句删除突破

时间：2026-08-01
朱雀测试消耗：约8次

---

## 核心突破

V49在科幻文本上实现0.0% AI率（从V42基线24.5%降至0%）。
方法：在V42基线规则不变的基础上，增加一步"从中间段落删除2-3个完整句子"。

## 失败教训

### V45（变强度执行）= 87.5% — 最严重退步
- 变强度阈值：前1/3用<20，中段<30，后1/3<15
- 多模式随机N30：4种模式随机选择
- 变概率感官删除：70%/30%/50%分段
- 新增 redistributeInfo：句子移动（产生重复文本bug）
- 新增 breakMetaPattern：段落缩减（产生碎片化单句段）

失败原因：
1. redistributeInfo函数有bug，把句子复制而非移动，产生重复文本
2. breakMetaPattern把段落砍成单句，产生碎片化
3. 变强度合并在前1/3保留了更多短句，而V43已证明短句是AI特征
4. 综合效果：引入了大量处理痕迹，这些痕迹本身被检测为AI

教训：用统一规则消除统一性会制造新的统一性，但用变强度规则制造的是"处理痕迹"而非"自然变化"

### V47（更激进）= 26.8% — 轻微退步
- 合并阈值从<25提高到<35
- 感官删除率从50%提高到75%
- N30用更大块的分组模式

失败原因：更激进合并让所有句子都变长，制造了"全部是长句"的新均匀性。方差没变，只是均值移了。

教训：不是改得更狠，是改得更不均匀

### V48（段落压平）= 24.4% — 无效果
- 把所有\n\n段落间隔压成\n，整篇文章变成一个超长段落
- 复现V16的段落结构

失败原因：V16的11.2%不是段落结构造成的。V48有完全相同的1段落13行结构，但仍是24.4%。

教训：V16的11.2%来自不同版本的规则代码，无法通过结构变化复现

## 成功突破：V49整句删除

### 方法
V42基线规则完全不变，在所有规则执行完之后、检测层之前，增加一步：
1. 把文本按\n\n分成段落
2. 只处理中间1/3的段落（不碰开头和结尾）
3. 对有4+个句子的段落，随机删除其中一个中间句子（不删首句不删末句）
4. 最多删3个句子

### 为什么有效
1. 创造"干净的信息缺口"：删整句不产生碎句，剩余文本完整通顺，只是少了信息
2. 打破"太完整"模式：方法论说"AI每个问题都解释得太完整"，删句子让某些地方"说到一半就停"
3. 打破信息密度均匀性：删句子前所有段落信息密度均匀，删后中间段落的密度变低
4. 不产生处理痕迹：删整句是人类编辑的自然操作（"这段话太多了，删一句"），不像删词会产生语法断裂

### 为什么删词（V47）无效而删句有效
- 删词（V47的感官词删除）：产生碎句、语法断裂、"缺失感"→处理痕迹→AI率升高
- 删句（V49的整句删除）：产生信息缺口、叙事跳跃、"省略感"→人类特征→AI率下降

### 效果差异
- V49a = 0.0%（删了2句，恰好打中了关键AI特征句）
- V49b = 10.8%（删了2句，但不是最关键的句子）
- 两次都远低于24.5%基线，方向正确
- 效果取决于删了哪些句子，但任何删除都比不删好

### 文本类型差异
- 科幻（叙述描写为主）：24.5% → 0% — 极佳
- 古风（叙述+对话混合）：80% → 40.2% — 良好
- 都市（对话密集）：100% → 100% — 无效（规则未触发，对话段落太短没有4+句可删）

### 对话文本的硬规则天花板
都市文100%无法降，因为：
1. 对话段落太短（1-2句），整句删除规则不触发
2. 对话太完整是AI特征，但需要语义理解才能修复
3. 硬规则只能做表面修剪（截断、删标签），不能改变对话逻辑
4. 这部分需要SKILL prompt层解决

## 方法论理解更新：从75%到90%

### 新增理解（+15%）
1. "太平均"是多维同时均匀，不是单个特征均匀
2. 用统一规则消除均匀性会制造新的均匀（V47证实）
3. 用变强度规则制造的是"处理痕迹"而非"自然变化"（V45证实）
4. 整句删除创造"干净的信息缺口"是打破"太完整"的有效手段（V49证实）
5. 删词产生碎句（AI痕迹），删句产生缺口（人类特征）——同样的"减法"，粒度决定成败

### 仍未理解的10%
1. "作者自己的选择"在硬规则中的具体实现
2. 对话内容重构需要语义理解
3. 具体vs抽象的判断边界
4. 如何让整句删除更稳定（V49a=0% vs V49b=10.8%的差距来源）

## 下一步方向

1. 增加删除句子数量：从最多3句增加到4-5句，看是否能让V49b也降到0%
2. 针对不同段落类型用不同删除策略：对话段落删对话轮次而非叙述句
3. 把整句删除规则推广到所有段落（不只是中间1/3）
4. 在SKILL prompt层实现"对话太完整"的修复（停顿、动作替代完整表达）
5. 把方法论核心"整篇文章语言规律"注入SKILL prompt，引导模型生成时就带不均匀性
